# Feasibility-Oriented Metamodel Website

Static HTML/CSS/JS site for the interactive feasibility-oriented metamodel and case-study implementations.

## Local preview

```bash
python -m http.server 8000
```

Open `http://localhost:8000/`.

## Pages

- `/` interactive metamodel generated from `metamodel_v2-Leonardo's touch.drawio.xml`
- `/cases/` case-study suite
- `/cases/cs1/` CS1 implementation
- `/cases/cs2/` CS2 implementation
- `/cases/cs3/` CS3 implementation
- `/cases/cs4/` CS4 implementation
- `/cases/cs5/` placeholder implementation folder

## Interaction

The main metamodel graph and the case-study implementation graphs are draggable. Use **Save layout** to store adjusted positions in local browser storage and **Reset layout** to return to the generated Draw.io layout.
